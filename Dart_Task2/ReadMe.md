Dart Task 2 – Object-Oriented Programming (OOP) in Dart
Overview

This task is focused on learning and applying the core principles of Object-Oriented Programming (OOP) using the Dart programming language. It aims to build a strong foundation by combining theoretical concepts with practical examples.

The repository includes both basic and advanced OOP implementations, along with real-world inspired programs to enhance code structure, reusability, and maintainability.

Objectives

The key goals of this task are:

To develop a clear understanding of OOP fundamentals
To implement OOP concepts effectively using Dart
To explore both basic and advanced OOP features
To write clean, modular, and reusable code
To strengthen problem-solving skills through practical examples
Learning Outcomes

By completing this task, I gained the ability to:

Create and utilize classes and objects in Dart
Apply inheritance to improve code reuse
Understand and implement encapsulation
Use abstraction to simplify complex logic
Work with interfaces in Dart
Apply polymorphism for flexible and dynamic behavior
Organize medium-scale applications using proper OOP design

Open terminal or command prompt
Navigate to the project directory
